# Architecture

PR001 реализован как статическая PWA на Vite и TypeScript без серверной части.

## Стек

- Vite для dev-сервера и статической сборки.
- TypeScript для модели данных и бизнес-логики.
- Vanilla TS для интерфейса, чтобы не добавлять лишнюю зависимость на раннем прототипе.
- IndexedDB через минимальный storage layer в `src/storage.ts`.
- CSS без UI-фреймворка.

## Слои

- `src/main.ts` — маршруты, экраны и обработчики UI.
- `src/types.ts` — доменная модель.
- `src/productLogic.ts` — расчет сроков, группировка и форматирование.
- `src/gs1Parser.ts` — локальный парсер GS1 Application Identifiers.
- `src/storage.ts` — локальное хранение продуктов в IndexedDB.
- `src/settings.ts` — локальные настройки напоминаний в `localStorage`.
- `public/sw.js` — базовый service worker для PWA.

## Сканирование

Экран `#/scan` использует `@zxing/browser` и `@zxing/library`. ZXing запускается только по кнопке пользователя, по возможности запрашивает заднюю камеру через `facingMode: environment`, декодирует `DATA_MATRIX` и оставляет `QR_CODE` как fallback для тестирования. При уходе со страницы сканирования камера освобождается.

Сканирование и парсинг выполняются локально в браузере. В PR002 нет backend, интернет-запросов и интеграции с API Честного знака.

## Хранение

Продукты хранятся только в IndexedDB текущего браузера. Настройки напоминаний хранятся в `localStorage`. В PR002 нет сетевых запросов к внешним API.

## Публикация

Сборка Vite отдает статические файлы в `dist/`. `base: './'` позволяет публиковать приложение на GitHub Pages, включая публикацию в подпапке репозитория.
