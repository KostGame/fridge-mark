## 5. Что проверить вручную

- Открыть приложение.
- Добавить продукт вручную.
- Выбрать срок годности быстрыми кнопками.
- Добавить фото.
- Открыть карточку продукта.
- Поменять статус на `opened`.
- Проверить группировку по срокам.
- Удалить продукт.
