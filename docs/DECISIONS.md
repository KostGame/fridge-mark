# Decisions

## PR001

- MVP делаем как PWA без сервера.
- Официальный API Честного знака пока не используем.
- Код не содержит API-ключей и не делает внешние API-запросы.
- Все пользовательские данные хранятся локально в браузере.
- Raw DataMatrix в будущих PR сохраняем полностью, чтобы не терять исходные данные маркировки.
- Максимум данных из маркировки пытаемся извлекать локально через GS1 AI parser.
- Уведомления в PWA считаем ограниченными: надежные локальные уведомления планируем через Capacitor APK.
- UI делаем mobile-first, темным и простым для использования одной рукой.
- React не добавляем в PR001: текущему прототипу достаточно vanilla TypeScript, а меньший стек проще поддерживать и публиковать на GitHub Pages.

## PR002

- Сканирование DataMatrix выполняем локально в браузере через ZXing.
- В hints приоритизируем `DATA_MATRIX`, а `QR_CODE` оставляем как fallback для ручного тестирования.
- Официальный API Честного знака по-прежнему не используем.
- Backend и API-ключи не добавляем.
- Продукт из считанного кода не создается автоматически: пользователь сначала видит raw-код, распарсенные поля, неизвестные AI и ошибки.
- При неполном парсинге все равно сохраняем полный `rawCode`, чтобы будущие версии могли перепарсить данные.
